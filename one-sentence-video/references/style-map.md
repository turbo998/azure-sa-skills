# 题材风格表（识别与禁忌；**配色/字体/动效真值在 style-ledger.json**）

本文件只做三件事：**识别题材**、**点名候选条目**、**声明题材禁忌**。
配色、字体、构图、动效、声音一律从 `references/style-ledger.json` 取——那里每条 style 有名字、色值、构图、seam、motif。

> **为什么不再在这里写色值**：本文件历史上给 tech-deep 写过 `#0B1020 + #38E1FF`（深蓝+霓虹青），
> 而同一段的禁忌又写着「禁深蓝网格、霓虹青大面积」——配色表与禁令互相矛盾，模型读到的是配色表。
> 这是「默认深蓝霓虹」最硬的来源。现已把色值全部移出，只留可寻址的条目 id。

## 使用方法

1. **识别题材**：按「识别关键词」命中；命中多个取全片占比最大者。
2. **查候选**：`python3 ~/.claude/skills/one-sentence-video/assets/style-query.py --genre <题材>`
   得到 3–5 条**浅底**候选（深色条目不出现在默认列表里）。
3. **唯一锁定**：整片只用一条 style 的 atoms；最多借邻近条目的 **1 个 layout**，不许借配色。
4. **受众修正**（默认 white-collar）：青少年 → 字号 +10%、节奏 -20%（更快）、accent 饱和度 +10%；中老年 → 字号 +20%、对比度拉满、动效时长 +30%。
5. **平台修正**（横屏默认 1920×1080）：横屏/B站 → 信息密度 +30%、可加数据角标；朋友圈/小红书 → 首帧当封面单独精修。

**深色是例外，不是风格**：所有 `dark: true` 条目（赛博 HUD / 金库蓝 / 夜场影院 / 记分牌 / 金属参数）
都必须由用户在方向比选里**明确选中**，并在 `design-spec.md` 写 `palette_source: <id>` + 拍板记录。
`palette-audit.py` 会拦。

## 题材禁忌（跨条目的硬约束，与所选 style 无关）

- `tech-deep`：禁手写体、圆萌元素、深蓝网格、玻璃态、霓虹青大面积。**不禁止暖米色底**（纸感目录就是暖米底，且是科技题材的默认候选）。
- `tech-minimal`：禁霓虹、纹理堆砌。
- `finance`：禁赛博霓虹、粉紫渐变、萌系圆角；A 股涨跌语义（红涨绿跌）不可反转。
- `guofeng`：禁霓虹、玻璃态、无衬线粗黑标题、冷蓝底。
- `emotional`：禁频闪、硬切、高饱和撞色、快速剪辑。
- `food`：禁冷色调、极简冷淡留白。
- `gaming`：禁水墨、衬线体、性冷淡米白。**霓虹在本题材合法**（唯一合法归属）。
- `career`：禁霓虹、暗底、炫技转场（内容可信度优先）。
- `sports`：禁萌系、柔焦、慢节奏。
- `news`：禁娱乐化特效、炫技 3D。
- `baby`：禁锐角、暗底、红黑撞色。
- `auto`：禁萌系、暖纸纹、快速闪切。
- `movie`：禁高饱和撞色、萌系、扁平干货风。
- `neutral`：禁任何题材专属元素（水墨/霓虹/金箔…）——兜底就保持中性。

## 全局禁令（所有题材通用）

- 全片统一 `back.out(1.7)` 或所有元素同时 fade-in
- **uniform fade+slide** / 全片同一个 `power3.out` 默认 / 每镜同一个 crossfade
- **深蓝底 + 青色网格** / 深空黑 + 霓虹青 / 玻璃态 / 无题材依据的粒子 / 网格 / 渐变文字 / 左侧色条卡片
- 三张等宽等高卡片并排（除非对比的正是 3 个真实对象）
- 原地抖动充数（idle wobble）：动效必须表达内容，不是呼吸
- 底部进度条 / 页眉页脚 / 章节编号

## 字体说明

字体随所选 style 条目的 `fonts` 字段走（三级：display / body / mono）。
`[内置]` = macOS 自带，零下载；`[下载]` = 需代理拉 woff2 进 `assets/fonts/` 并 `@font-face` 指文件。
任何情况下禁止只挂 Google Fonts `<link>` 不写 `@font-face`。
