## 意图
左边三个候选，右边一个结论，中间三条线收成一条——"归因"这个抽象动作的物理形态。

## 适用
归因 / 筛选 / 从多个候选收敛到一个结论；任何「三选一」的推理镜。

## 构图
| 区 | x | 宽 |
|---|---|---|
| 左栏（候选） | 100 | 830 |
| **走廊** | 930 | **140** |
| 右栏（结论） | 1070 | 670 |

左栏每行：名称 300 / 标签 80 / 条 360 / 数字 90。

**走廊宽度是关键**：低于 100px 三条线会糊成一坨，"并成一条"这个动作就看不见了。

## 时间表
| t | 动作 |
|---|---|
| 0.0–1.2 | 三行候选依次落位（stagger .12） |
| 1.4 | 先给一个**空边框**（答案的位置） |
| 2.4 | 三条线从各自起点出发，1.6s 后汇入走廊 |
| 3.2 | 结论卡落入空边框 |

## 位先立、答案后落
结论出来前 1.4s 先给空边框，答案落进来时才有"填进去"的感觉——
同时把这段空白从"空"变成"等待"。

## 参数表
| 参数 | 典型值 | 调节手感 |
|---|---|---|
| 左栏宽 | 830 | 再窄候选读不完 |
| **走廊宽** | **140** | **<100 三条线糊成一坨；>200 读作空白列** |
| 右栏宽 | 670 | 结论卡最小可读宽 |
| 行内配比 | 300 / 80 / 360 / 90 | 数字列 <70 会挤 |
| 空边框提前 | 1.4s | 少于 0.8s 没有「等待」感 |

## HyperFrames 要点
- 收敛线用 SVG path + `stroke-dashoffset`（seek 安全）。
- 空边框与结论卡可以是同一个 clip 的两个状态？**不行**——用两个平铺 clip 硬切接力。

## 声音
`swipe` 三条线汇入（同一声，不要三声），`chime` 结论落定。

## 何时不用
- 候选少于 2 个：没有"收敛"，直接给结论。
