## 意图
把「概念分类与多层架构拓扑（如 Agent → MCP 协议层 / Skill 方法层 / 本地 Tools 执行层）」变成从左向右生长、按焦点逐支点亮并自动压暗非焦点分支的渐进式空间图谱，解决多概念同屏时观众视线迷失的问题。

## 适用
- Agent 架构拆解、MCP vs Skill vs Tool 概念辨析、系统分层拓扑推演。
- 需要在一镜内先建立全局树状骨架，再依次对单一层级进行聚光灯式深度剖析的镜头。

## 时间表
| t (s) | 动作 |
|---|---|
| `0.00–0.45` | 左上章节编号胶囊 `[01] 核心问题` 滑入并锁定，根节点落位 |
| `0.45–1.20` | 三条三次贝塞尔曲线通过 `stroke-dashoffset` 从左向右生长（stagger `0.14s`），三层分支节点依次点亮 |
| `1.20–2.60` | **焦点聚光灯阶段 1**：协议层（薄荷绿 `#4ADE80`）放大至 `scale: 1.08`，方法层与执行层连同连线自动降暗至 `opacity: 0.25`，SVG 连线脉冲流光划过 |
| `2.60–3.80` | **焦点聚光灯切换**：焦点移至方法层（丁香紫 `#A78BFA` `scale: 1.08`），右侧同步弹出圆环痛点仪表盘（`90% 容易混淆` `#FB7185`） |
| `3.80–4.50` | 全树恢复 `opacity: 1.0` 全景定格，随后沿当前焦点节点执行 `scale-through` 穿场进入下一镜 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|---|---|---|
| 焦点放大倍率 (`focus_scale`) | `1.08` | `<1.04` 看不出主次切换；`>1.15` 会遮挡上下相邻分支或撑破安全区 |
| 非焦点降暗透明度 (`dim_opacity`) | `0.25` | `<0.15` 树状上下文彻底消失，观众忘了全局结构；`>0.45` 聚光灯效应不足 |
| 贝塞尔控制点水平偏移 (`ctrl_dx`) | `130px`（间距的 50%） | `<80px` 折线感生硬；`>180px` 曲线在节点入口处过于弯曲 |
| 连线生长时长 (`draw_dur`) | `0.42s` (`power3.out`) | `<0.25s` 像闪烁跳出；`>0.7s` 拖慢讲课节奏 |
| 同屏最大节点数 | `≤ 7`（1 根 + 3 分支 + 3 子叶/仪表） | 超过 7 个节点会变成密集架构图，手机端完全无法阅读 |

## HyperFrames 要点
- 每个分支节点及其 SVG 连线必须是**独立的平铺 clip**（严禁嵌套 clip 或 tween 子元素）。
- 焦点切换时的 `scale: 1.08` 与非焦点 `opacity: 0.25` 直接作用于各自节点 clip 本体，使用 `power3.out` 保持切换顺滑且 seek 安全。
- SVG 脉冲流光采用双层 `<path>`：底层固定半透明连线，顶层短虚线 `stroke-dasharray: 24 260` 配合确定性 `stroke-dashoffset` 线性推进。

## 声音
- 分支生长：每条贝塞尔线到达节点时触发轻脆 `tick`（gain `0.25`）。
- 焦点聚光灯切换：配短促 `swipe` 或轻 `whoosh`（gain `0.30`），痛点圆环闭合时触发 `chime`（gain `0.45`）。

## 何时不用
- 线性先后顺序的流水线（无分支父子层级关系）：请改用 `funnel-stage-filter`。
- 只有 2 个平级对象的正反对比：请改用 `split-compare` 或 `two-column-corridor`。
